## Зачем это нужно

Некоторым корпоративным программам необходимы дополнительные условия работы для обеспечения информационной безопасности.

Лаунчер следит за этим:

- Запущенные программы работают с дополнительными условиями, все остальное как обычно.
- Лаунчер в реальном времени отслеживает выполнение условий запущенных программ.
- Условие перестало выполняться - программы из лаунчера закрываются вместе со всеми дочерними процессами.

## Как пользоваться

1. Скачайте установщик из [Releases](https://github.com/psibia/safe-launcher/releases/latest) и установите. Лаунчер работает по ключу лицензии: при первой установке его вводят один раз.
2. Добавьте программы: кнопкой "Добавить приложение" (отметьте программы из меню "Пуск" или выберите в проводнике) или перетащите в окно `.exe` или ярлык.
3. Укажите условия для всех программ или для каждой программы отдельно.
4. Запускайте программы с плиток лаунчера. Цвет кольца вокруг иконки показывает состояние:
   - зеленое: условие выполняется;
   - желтое: ожидание сети;
   - серое: запущено мимо лаунчера.

Свое условие и прочие опции для отдельной программы настраиваются из меню ее плитки. Там же программу можно разово запустить без сети, а условие "Без сети" запускает ее так всегда.

> Все, что программа запустила сама, считается ее частью. Если браузер открылся из приложения по ссылке, он закроется вместе с приложением.

## Как это устроено

```
 Лаунчер
   │  запускает программы в задании Windows
   │  отвечает ядру, чей процесс
   ▼
 Служба "Безопасный лаунчер - сеть" (сощдается от имени системы)
   │  запускает ядро и ставит фильтры WFP
   ▼
 Ядро launcher-core.exe
      выполняет маршрутизацию условий
```

**Ядро** (`launcher-core.exe`). Это форк sing-box (далее - коробка) 1.14.3 с небольшими правками:

1. Обычная коробка различает программы только по пути к exe. Доработанное ядро коробки спрашивает лаунчер по именованному каналу, из какого задания процесс, и получает метку приложения. Правила маршрута работают по этой метке.
2. Используется только ipv4
3. Поддерживается AmneziaWG всех версий (1.0–3.1): файл .conf или ключ vpn:// от своего сервера в AmneziaVPN.
4. Несколько подключений WireGuard или AmneziaWG работают одновременно: ответы серверов не путаются, даже если у подключений одинаковый адрес в туннеле.

Правки лежат в [core/patches](core/patches), сборка воспроизводится скриптом [core/build.ps1](core/build.ps1). Подробнее в [core/README.md](core/README.md).

## Сборка

Нужны Windows, .NET 8 SDK и [Inno Setup 6](https://jrsoftware.org/isdl.php).

```powershell
git clone https://github.com/psibia/safe-launcher.git
cd safe-launcher
installer\build-installer.cmd
```

Готовый установщик и его подпись (`.exe.sig`) появятся в `installer\Output`. Ядро скрипт берет готовым, а если его нет, собирает из исходников (тогда нужны Git и Go).

Выпуски подписываются ключом: по подписи лаунчер проверяет обновление и ставит его без запроса прав Windows. При первой сборке скрипт создает закрытый ключ `installer\update-signing-key.pem` и открытый `installer\update-public-key.pem`. Закрытого ключа в репозитории нет: сохраните его копию отдельно, без него следующие выпуски не подписать. Открытый ключ хранится в репозитории. К релизу на GitHub прикладывайте оба файла из `installer\Output`, подробнее в [docs/DETAILS.md](docs/DETAILS.md#обновления).

Установщик ставит лаунчер по ключу лицензии, поэтому для сборки нужен файл `installer\license-hashes.txt` с хешами ключей. В репозитории его нет, подробнее в [docs/DETAILS.md](docs/DETAILS.md#ключ-лицензии).

Для разработки: откройте `KillSwitchLauncher.sln` в Visual Studio, а службу и ядро поставьте командой `tools\update-service.cmd`. Тесты находятся в `dotnet test`.

## Структура

| Папка | Что внутри |
|---|---|
| `KillSwitchLauncher` | лаунчер |
| `SafeLauncher.Service` | служба Windows |
| `core` | коробка и скрипт сборки ядра |
| `installer` | установщик Inno Setup |
| `KillSwitchLauncher.Tests` | тесты (xUnit) |
| `prototype` | проверка службы и ядра на компьютере |
| `tools` | установка службы и ядра при разработке, подпись выпусков |
