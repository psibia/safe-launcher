## Зачем это нужно

Некоторым программам нужна особая сетевая среда: определенный сетевой адаптер или определенное подключение. Если среда пропала, программа обычно молча продолжает работать как ни в чем не бывало.

Лаунчер следит за этим:

- **Условия только для выбранных программ.** Discord, браузер или рабочая утилита работают с дополнительными условиями, все остальное как обычно.
- **Kill-Switch.** Условие перестало выполняться, и программы из лаунчера закрываются сразу, вместе со всеми дочерними процессами.
- **Никаких обходных путей.** Пока условие действует, программа не сможет сама выбрать другую сетевую карту.

## Возможности

- **Условие запуска** для каждой программы: общее для всех или свое.
- **Условие по адаптеру:** программа работает, только пока активен нужный сетевой адаптер.
- **Условие по подключению:** трафик программы идет только через выбранное подключение лаунчера. Подключение добавляется ссылкой, подпиской или файлом настроек.
- **Проверка подключения:** задержка, страна и внешний IP, а если не работает, понятная причина.
- **Блокировка обходных путей** через фильтры Windows (WFP), только для программ лаунчера.
- **Исключения:** отдельные сайты программы можно пустить напрямую.
- **Журнал DNS:** какие домены запрашивает программа.
- Ярлыки, программы из Microsoft Store, трей, автозапуск с Windows, обновления из GitHub.

## Как пользоваться

1. Скачайте установщик из [Releases](https://github.com/psibia/safe-launcher/releases/latest) и установите. Ничего дополнительно ставить не нужно.
2. При первом запуске мастер поможет задать общее условие запуска.
3. Добавьте программы: кнопкой "Добавить" или перетащите в окно `.exe` или ярлык.
4. Запускайте программы с плиток лаунчера. Цвет кольца вокруг иконки показывает состояние:
   - зеленое: условие выполняется;
   - желтое: ждет сеть;
   - серое: запущено мимо лаунчера или без условия.

Свое условие, исключения и журнал DNS для отдельной программы настраиваются из меню ее плитки.

> Все, что программа запустила сама, считается ее частью. Если браузер открылся из Discord по ссылке, он закроется вместе с Discord.

## Как это устроено

```
 Лаунчер (WPF, права пользователя)
   │  запускает программы в задании Windows (Job Object)
   │  отвечает ядру, чей процесс
   ▼
 Служба "Безопасный лаунчер - сеть" (от имени системы)
   │  запускает ядро и ставит фильтры WFP
   ▼
 Ядро launcher-core.exe (доработанный sing-box)
      свой сетевой адаптер, маршрут по программам
```

**Лаунчер** (`KillSwitchLauncher`, .NET 8, WPF). Интерфейс, настройки, слежение за условиями. Каждая программа запускается в своем задании Windows: так лаунчер видит все ее процессы, даже если она перезапустилась через Update.exe, и может закрыть их разом. С включенным Kill-Switch, если лаунчер упадет, Windows сама закроет программы.

**Служба** (`SafeLauncher.Service`). Нужна, потому что сетевой адаптер и фильтры требуют прав администратора, а лаунчер работает с обычными правами. Служба выполняет только команды лаунчера и проверяет их. Ядро и фильтры живут, пока работает лаунчер: закрыли его, и компьютер работает как обычно.

**Ядро** (`launcher-core.exe`). Это форк [sing-box](https://github.com/SagerNet/sing-box) 1.14.3 с тремя небольшими правками:

1. **Чей процесс.** Обычный sing-box различает программы только по пути к exe. Discord из лаунчера и тот же Discord с рабочего стола для него одинаковы. С правкой ядро спрашивает лаунчер по именованному каналу, из какого задания процесс, и получает метку приложения. Правила маршрута работают по этой метке.
2. **Имя сайта вместо адреса.** Ядро передает дальше имя сайта, а не IP, который вернул местный DNS. Подмененный ответ DNS ничего не испортит.
3. **Сети без IPv6.** Если на сетевой карте выключен IPv6, подключения работают по IPv4.

Правки лежат в [core/patches](core/patches), сборка воспроизводится скриптом [core/build.ps1](core/build.ps1). Подробнее в [core/README.md](core/README.md).

## Сборка

Нужны Windows, .NET 8 SDK и [Inno Setup 6](https://jrsoftware.org/isdl.php).

```powershell
git clone https://github.com/psibia/safe-launcher.git
cd safe-launcher
installer\build-installer.cmd
```

Готовый установщик появится в `installer\Output`. Ядро скрипт берет готовым, а если его нет, собирает из исходников (тогда нужны Git и Go).

Для разработки: откройте `KillSwitchLauncher.sln` в Visual Studio 2022, а службу и ядро поставьте командой `tools\update-service.cmd`. Тесты: `dotnet test`.
